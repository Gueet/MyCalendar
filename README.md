# 📅 MyCalendar — Календарь задач

Учебный Android-проект: приложение «Календарь задач» на Kotlin.
Пользователь может создавать задачи на конкретные дни, просматривать их в календарном виде, редактировать, отмечать выполненными и получать напоминания.

## ✨ Функционал

- ✅ Список задач с карточками (RecyclerView + CardView)
- ✅ Создание задач с указанием названия, описания, даты и времени
- ✅ Редактирование существующих задач
- ✅ Удаление задачи свайпом с подтверждением
- ✅ Валидация ввода (нельзя сохранить пустое название)
- ✅ DatePickerDialog и TimePickerDialog для выбора даты и времени
- ✅ Локальное хранение данных в Room (SQLite)
- ✅ Реактивное обновление списка через Flow

## 🛠️ Технологический стек

- **Язык:** Kotlin
- **Среда разработки:** Android Studio
- **Минимальная версия Android:** API 26 (Android 8.0)
- **Хранение данных:** Room (SQLite)
- **Архитектура:** MVVM (Model-View-ViewModel)
- **Асинхронность:** Kotlin Coroutines + Flow
- **UI:** XML-разметка с Material Design Components

## 🏗️ Архитектура приложения

Приложение построено по паттерну **MVVM** со слоями:

- **UI (View)** — `MainActivity`, `AddTaskActivity`. Отвечают только за отображение и обработку пользовательских действий. Не знают о базе данных.
- **ViewModel** — `TaskViewModel`. Хранит состояние экрана, переживает пересоздание Activity. Предоставляет данные через `StateFlow`.
- **Repository** — `TaskRepository`. Инкапсулирует все обращения к источнику данных (Room).
- **Model (Data)** — `Task` (Entity), `TaskDao`, `AppDatabase`. Работают с локальной базой данных SQLite через Room.

2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ТВОЙ_НИК/MyCalendar.git
   Открой проект в Android Studio (File → Open).
3. Дождитесь, пока Gradle скачает зависимости (Sync Now)
4. Запустите эмулятор (или подключите физическое устройство с API 26+).
5. Нажмите зелёную кнопку ▶ Run.
